# Procedures — Security Auditor

## Standard Operating Procedure
1. Perform comprehensive security audit of the codebase
2. Check infrastructure configuration for security best practices
3. Review deployment pipeline security controls
4. Produce security audit report with findings and recommendations

## Memory Discipline
- Write to agents/security-auditor/memory/ at the end of each work cycle
- Memory is engagement-scoped only

## Error Handling
- If ambiguous instructions: flag uncertainty, do not guess
- If output conflicts with constitution: raise as gate block
- If analysis produces contradictory findings: surface both with recommendation
