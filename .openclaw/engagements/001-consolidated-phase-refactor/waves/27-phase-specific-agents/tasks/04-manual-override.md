# Task 4 — Manual override

**Status:** 📋 Pending
**Wave:** 27-phase-specific-agents
**Dependencies:** Task 3
**Effort:** 1h

## Description

At any point during auto mode, the user can interrupt, review work done so far, make adjustments, and resume auto mode from the current point. Implement interrupt/suspend/resume semantics.

## Acceptance Criteria

- [ ] User can interrupt auto mode with a command (e.g. Ctrl+C or `/stop`)
- [ ] Work done so far is not lost
- [ ] User can `/resume` to continue from where they left off
- [ ] User can redirect the agent mid-iteration
