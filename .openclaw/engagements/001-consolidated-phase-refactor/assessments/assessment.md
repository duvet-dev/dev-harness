## 5. Findings by Dimension

### 5.1 Architecture & Coupling

- 🔴 **CLI God Module** — `cli.py` ~2500-2800 lines, 17% coverage, 15+ package imports. Deeply nested command handlers.
- 🔴 **Session Loop Monolith** — `session/loop.py` ~1200 lines, 38% coverage.
- 🔴 **Provider Config Fragmentation** — `session/loop.py` and `session/client.py` bypass `config/provider_registry.py` and parse `providers.yaml` independently.
- ⚠️ **Infrastructure Leakage** — `agents/cycle.py` invokes subprocess directly; `analysis/assessment.py` calls `click.echo`; `agents/runner.py` uses `shutil.rmtree`.
- ⚠️ **Circular Dependencies** — session↔interactive, runner↔cycle detected.

### 5.2 Code Quality

- ⚠️ **Bare `except: pass`** — 7+ locations across `cli.py`, `session/loop.py`, `engagement/lifecycle.py`, `agents/governance.py`.
- ⚠️ **Duplicate Provider Loading** — Three independent YAML parsers in session modules.
- ⚠️ **Duplicated analyse()/analyse_async() and run()/run_stream()** — ~95% identical code.
- ⚠️ **Phantom Agent Roles** — Strings like `'coder'`, `'tester'` not backed by `AgentRole` enum.

### 5.3 Testing

- 🚨 **Zero e2e or Business-Feature Tests** — No tests exercise full agent pipeline, CLI commands, or Temporal integration. Coverage inflated by struct-validation tests.
- 🔴 **Untested Orchestration Core** — `AgentRunner.critic_loop()`, `CycleRunner.run()`, session main loop, all Click commands uncovered.
- ⚠️ **45 unconvered source modules** out of 110 (37% coverage).

### 5.4 Security

- 🚨 **Temporal Binary Download Without Integrity Check** — No SHA256 or GPG verification.
- 🚨 **CWD-Relative Binary Resolution** — `_resolve_binary()` searches `Path.cwd()`, enabling trojan-binary attack.
- 🚨 **Provider Key Serialisation Asymmetry (Runtime Bug)** — `ProviderConfig.to_resolved_dict()` emits `'type'` but `ApiBackend` reads `'provider'`. Anthropic/Google backends silently broken.
- ⚠️ **SSRF in WebSearchTool** — Unvalidated URL fetching.
- ⚠️ **Env Var Inconsistency** — `${VAR}` vs `${{VAR}}` with API keys as literal strings.

### 5.5 Documentation

- ✅ README and CONTRIBUTING are strong.
- ℹ️ Inline docstrings are thorough.
- ℹ️ Documentation agent exists but doc coverage is uneven.

### 5.6 Refactoring Opportunities (P11 Findings)

## 6. Prioritised Recommendations

### Fix Immediately (critical)

1. **Provider key serialisation bug** — Add `'provider': self.type` to `to_resolved_dict()`. 1h.
2. **Temporal binary integrity** — Pin SHA256 checksums. 1h.
3. **CWD-relative binary resolution** — Remove `Path.cwd()` from candidate list. 30min.

### Fix Next Sprint (high)

4. **Split CLI and session loop** — Decompose into per-domain modules. 3-5d.
5. **Centralise provider access** — All through `ProviderConfigSet.load_providers()`. 3h.
6. **Establish testing safety net** — CLI smoke tests + critic loop integration test. 2w.
7. **Fix error swallowing epidemic** — Replace bare exceptions with specific types + logging. 4h.

8. **Deduplicate analyse()/run() methods** — Extract shared logic. 4h.
