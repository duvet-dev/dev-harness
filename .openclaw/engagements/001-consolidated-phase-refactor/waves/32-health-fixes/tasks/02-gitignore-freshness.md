# Task 2 — Add .harness-freshness.yaml to .gitignore

**Status:** 📋 Pending
**Wave:** 32-health-fixes
**Dependencies:** None
**Effort:** 0.1h

## Description

`.harness-freshness.yaml` is a runtime metadata file generated by the harness — tracks current branch, head SHA, and reconciliation state. It changes on every harness operation and should not be tracked in git. Currently it shows as a permanent dirty file in `git status` and triggers the "Git working tree has uncommitted change(s)" warning.

## Fix

Add `.harness-freshness.yaml` to `.gitignore`.

## Acceptance Criteria

- [ ] `.harness-freshness.yaml` no longer appears in `git status` as dirty
- [ ] `harness shell` no longer shows "Git working tree has 1 uncommitted change(s)" about freshness
- [ ] File is still present on disk (just untracked)
